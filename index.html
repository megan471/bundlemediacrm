🔑 Google API Setup Guide
This lets Bundle Media CRM read images directly from your Google Docs. Takes about 15 minutes.
Step 1 — Create a Google Cloud Project
  1. Go to console.cloud.google.com
  2. Click New Project → name it Bundle Media CRM → Create
  3. Make sure the new project is selected in the top dropdown
Step 2 — Enable the APIs
  1. In the left menu go to APIs & Services → Library
  2. Search for Google Docs API → click it → Enable
  3. Search for Google Drive API → click it → Enable
Step 3 — Create an API Key
  1. Go to APIs & Services → Credentials
  2. Click + Create Credentials → API Key
  3. Copy the key and paste it above
  4. Click Edit API Key → under API restrictions select Google Docs API and Google Drive API
  5. Under Application restrictions → select HTTP referrers → add megan471.github.io/*
Step 4 — Create OAuth Client ID
  1. Go to APIs & Services → Credentials → + Create Credentials → OAuth Client ID
  2. Application type: Web application
  3. Name: Bundle Media CRM
  4. Under Authorised JavaScript origins add: https://megan471.github.io
  5. Click Create → copy the Client ID and paste it above
Step 5 — Configure OAuth Consent Screen
  1. Go to APIs & Services → OAuth Consent Screen
  2. User type: External → Create
  3. App name: Bundle Media CRM, support email: your email
  4. Under Scopes → Add: .../auth/documents.readonly and .../auth/drive.readonly
  5. Under Test users → add megan@bundlemedia.africa and stacey@bundlemedia.africa
  6. Save and continue
✅ Once done

Paste your API Key and Client ID in Settings and click Test Connection. When it says Connected, your Docs will be fully readable including images.
